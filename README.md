# Krugerrand Bot

A Discord bot with live gold and Krugerrand prices, and Krugerrand facts. It runs on **Cloudflare Workers**, so it costs nothing on the free tier and needs no server.

## Commands

| Command | What it does |
|---|---|
| `/goldprice` | Live spot gold price in USD per troy ounce. |
| `/krugerrandprice` | Estimated price of a 1 oz Krugerrand: spot plus a typical 3% dealer premium. |
| `/krugerrandfact` | A random Krugerrand fact, generated by AI or picked from a curated list. |

The commands work in servers, in DMs, and as a user-installed app.

## How it works

```
Discord command ──► fetch() /interactions → verify signature → "thinking…" → fetch data → edit reply
```

Discord waits only 3 seconds for an answer, and the price and AI calls can take longer. So the Worker answers straight away with a deferred reply ("Krugerrand Bot is thinking…"), fetches the data in the background, and then edits the reply.

- **Gold price:** [gold-api.com](https://gold-api.com), falling back to Swissquote's public quote feed. Neither needs an API key.
- **Facts:** `openai/gpt-oss-120b` through the [Hugging Face inference router](https://huggingface.co/docs/inference-providers), on Groq first and then on any other provider. If every attempt fails or no key is set, the bot picks one of 16 curated facts. AI answers carry an "AI, may contain mistakes" footer.

## Setup

Infrastructure is Terraform in [`infra/`](infra/): the Worker with its bindings and secrets, and its workers.dev route. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) runs it. Pull requests get tests and a `terraform plan` in the run summary. Pushes to `main` also run `terraform apply`, set the Discord app's Interactions Endpoint URL, and register the slash commands.

Terraform state shares the NHL Trade Tracker's R2 bucket, `nhl-trade-tracker-tfstate`, under the key `krugerrand-bot/terraform.tfstate`, so the same R2 token works for both.

### 1. Discord application
From https://discord.com/developers/applications, select **Krugerrand Bot**:
- **General Information:** copy the **Application ID** and **Public Key**.
- **Bot:** the **bot token** (select **Reset Token** if you don't have it).
- **Installation:** scopes `bot` and `applications.commands`. The bot only replies to commands, so it needs no extra permissions.

### 2. GitHub configuration
In **Settings → Secrets and variables → Actions**:

| Name | Kind | Value |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | Secret | Cloudflare API token with **Workers Scripts: Edit** (the NHL Trade Tracker's CI token works) |
| `R2_ACCESS_KEY_ID` | Secret | R2 token with Object Read & Write on `nhl-trade-tracker-tfstate` |
| `R2_SECRET_ACCESS_KEY` | Secret | Same R2 token |
| `DISCORD_BOT_TOKEN` | Secret | Bot token. Used by CI only (endpoint URL and command registration), never by the Worker. |
| `HUGGINGFACE_API_KEY` | Secret, optional | Hugging Face token with **Make calls to Inference Providers** |
| `CLOUDFLARE_ACCOUNT_ID` | Variable | Cloudflare account ID |
| `DISCORD_APPLICATION_ID` | Variable | Application ID |
| `DISCORD_PUBLIC_KEY` | Variable | Public Key |
| `DISCORD_DEV_GUILD_ID` | Variable, optional | A server ID. Commands register there instantly instead of globally, which can take up to an hour. |

### 3. Deploy
Push to `main` or run the **Deploy** workflow by hand. When the run finishes, the bot is live: CI points Discord at `https://krugerrand-bot.graniero-jonathan.workers.dev/interactions`, and Discord checks the endpoint as it saves it. Then try `/goldprice` in Discord.

To run Terraform locally, export `CLOUDFLARE_API_TOKEN`, the R2 keys as `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`, and the `TF_VAR_*` values the workflow uses, then:
```bash
npm run build
cd infra
terraform init -backend-config='endpoints={s3="https://<account-id>.r2.cloudflarestorage.com"}'
terraform plan
```
Don't use `wrangler deploy`: Terraform owns the Worker and would overwrite it on the next apply.

## Development

```bash
npm test                         # unit tests (network calls are stubbed)
npm run typecheck
cp .dev.vars.example .dev.vars   # fill in the Discord values
npm run dev                      # local Worker on http://localhost:8787
npm run register-commands        # upload the command definitions
```

## Project layout

```
src/index.ts             Worker entry: fetch() handles Discord interactions
src/discord/verify.ts    Ed25519 request signature check
src/discord/commands.ts  Slash command definitions, deferred replies and embeds
src/discord/api.ts       Editing a deferred reply through the interaction webhook
src/gold.ts              Live gold price with a fallback source, Krugerrand premium
src/facts.ts             AI facts through Hugging Face, curated fallback facts
scripts/                 One-off tools (command registration)
infra/                   Terraform: Worker, bindings, workers.dev route
.github/workflows/       CI: test, plan, apply, set endpoint, register commands
test/                    Vitest tests with signed requests and a stubbed fetch
```
